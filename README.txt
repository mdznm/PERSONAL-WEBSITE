Open index.html for Home and the Gallery. Use the menu to open About Me, Experience, Skills, Interest and Contact.
Upload all HTML pages, style.css and assets/ together to GitHub Pages. The site runs without a build step.

Put your own files inside assets/ using the names below. Match capitalisation on GitHub.

Home: home/myprofile-cutout.png. The site wordmark is branding/hafizan-wordmark.png.
Gallery: use gallery/2022/ through gallery/2026/. Each year uses cover.jpg and numbered photos.
To add a photo, put it in the year folder and copy a <figure> at the end of that year’s photo grid in index.html. Update its image filename, alt text and caption.
About: about/about.jpg. Put resume.pdf directly in assets/.
Experience: use experience/experience.jpg and experience/smk-inanam.png. Internship photos go in internship/ as internship-1.jpg through internship-5.jpg.
Skills: use skills/ for canvalogo.jpeg, claudelogo.png, exa.png, htmllogo.png, skill-5.jpg and skill-6.jpg.
Interest: put cooking1.jpg through cooking6.jpg in interest/.
Contact: put contact-email.jpg, contact-linkedin.jpg and contact-social.jpg in contact/.

The grey spaces are placeholders until your files are added. Edit the captions and contact details in the corresponding HTML files.
